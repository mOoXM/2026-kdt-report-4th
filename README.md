# 물리학Ⅰ 개념 진단과 유사문항 추천 시스템

K-Digital Training 4차 — 제출 코드 (김지수)

ㄱ·ㄴ·ㄷ형 물리 문항에서 학생이 **보기 하나하나를 어떻게 판단했는지** 받아, 세부 개념 단위로 약점을 진단하고
비슷한 문항으로 연습을 잇는 플랫폼입니다. 코드는 [`code/`](code/) 에 있고, 구성과 실행 방법은 [code/README.md](code/README.md) 에 있습니다.

## 코드 한눈에

- **백엔드** FastAPI + SQLite (`code/src/physics_lab/`) — 계정 · 응답 · 시험 운영 API, 진단 엔진, 유사 문항 엔진
- **프론트엔드** React + TypeScript (`code/frontend/`) — 학생 앱(태블릿 풀이 · 필기) · 강사 앱(반 · 시험지 · 결과 표)
- **실행** `uv sync` → `uv run pl-demo-seed` → `npm run build` → 서버

> 제출 코드는 공개본입니다. 서비스 전체는 그대로 동작하지만 세부 개념 체계 · 진단 방식 · 유사도 결합은
> 단순한 기본 구현이며, 문항은 직접 만든 데모 문항 10개입니다.
